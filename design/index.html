07

Design review & HIG 2026 changes

Key problems found in the current (Old) design

  • 6-tab bottom bar is overloaded. Labels are truncated ("Трен-ки", "Прогр."); Apple recommends 5 or fewer tabs.
  • Filters hide behind a 🔍 accordion. Every browse tab needs an extra tap to even see the filters, and opening them shoves content down.
  • Meta data is a wall of emoji pills. 📍🏘️📅🏃 chips all look identical, so nothing reads as primary information.
  • Home is just five link cards. No personalization, no live content, no hierarchy - it duplicates the tab bar.
  • Cards have no real action. Events/Places sometimes link out; Coaches and Programs offer no way to contact or open a detail.
  • Free-text number filters. Age / experience are raw numeric inputs with "18-80" placeholders - awkward on mobile and easy to mis-enter.
  • Inline CRUD form fights the tab bar. The 9-field create form renders as a card under the fixed bottom nav, which overlaps the lower fields.
  • Loading is a bare spinner / ⏳ emoji. Layout jumps when data lands; no skeletons.
  • Empty states are dead ends. Same "не найдены" copy everywhere, with no reset action.
  • Contrast & touch targets. Light teal-on-white meta pills and 54px tab items sit below comfortable contrast / 44pt targets.

HIG 2026 improvements applied in the New design

  • 5-tab Liquid-Glass tab bar. Programs + Coaches fold under a single "Ещё", full labels, translucent material with depth and a safe-area inset.
  • Search + horizontal filter rail, then a bottom-sheet for advanced filters with a grabber and a result-count Apply button - a standard iOS commit pattern.
  • SF-style large titles with an eyebrow line, tighter type scale and tabular numerics; consistent 8pt spacing rhythm.
  • Information hierarchy in cards: date badges, brand-tinted primary pills vs neutral secondary pills, edge-to-edge photos, disclosure chevrons.
  • Every card drives an action - "На карте", "Связаться с тренером", "Написать" - matched to intent.
  • Native controls for numeric ranges: a draggable slider and segmented control with an explicit default instead of free-text fields.
  • Create flow becomes a full-screen modal with Cancel/title/step header, paired date+time, focus states and a sticky primary button - no nav-bar collision.
  • Content-shaped skeletons replace spinners, so there is no layout shift.
  • Actionable empty states that name the active filters and offer one-tap reset.
  • Accessibility: deeper brand teal for AA contrast, 44pt+ targets, FAB for "create", and a determinate branded launch screen. Dynamic-Island-aware top spacing throughout.

Design guidelines (for developers)

New design

A quick reference for building the New design in code. Tokens below are the same CSS custom properties used in this file (and adapt to light / dark); mirror them in the app's theme.

Icons - Lucide

Use the Lucide icon set everywhere. In React install lucide-react and render e.g. <Calendar />; on the web you can also use <i data-lucide="calendar"> + lucide.createIcons(). Icons are outline, 2px stroke, drawn in currentColor and sized to the text (~16-24px). Do not mix in emoji or another icon family. Spacing & radius

  • Base grid8pt
  • Card radius22px (--n-radius)

  • Pills9px
  • Touch target≥44pt

Component rules

  • Tab bar - at most 5 items in a Liquid-Glass floating bar with full labels; overflow goes under "Ещё". Respect the safe-area inset.
  • Filters - a sticky search field plus a horizontal chip rail for quick filters; advanced filters open in a bottom sheet with a grabber and a result-count Apply button.
  • Cards - every card drives exactly one primary action. Brand-tinted pills carry primary info (time, category); neutral pills are secondary.
  • Buttons - primary (brand gradient), ghost (brand on a tinted fill), tint (neutral), and danger (red) for destructive actions. Destructive is always red.
  • Lists - use a date badge for events and a disclosure chevron when a row opens a detail view.
  • States - replace spinners with content-shaped skeletons; empty states name the active filters and offer a one-tap reset.
  • Create flow - a FAB opens a full-screen modal (Cancel / title / sticky primary button); never an inline form fighting the tab bar.
  • Accessibility - AA contrast, 44pt+ targets, support Dynamic Type, and keep status-bar / Dynamic-Island spacing.
